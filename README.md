# Muse 娘化形象分享包

这是给 Meta 的个人 AI 助手 Muse 定制的娘化形象，由 Steven 和他的 Muse 一起迭代选定（2026-11-06）。

## 形象设定
- 银紫色长发，粉色花朵发饰
- 白底 + 蓝条纹华丽长裙（配色取自 Muse App 的白底蓝条界面）
- 蕾丝、多层珍珠项链，腰侧标志性的蓝白条纹大蝴蝶结

## 内容清单
- `avatar-main.webp` / `avatar-main.png` — 主形象图（定妆图）
- `states/` — 行为状态动画（每段 8 秒）
  - `idle-and-connecting.mp4` — 待机 / 连接中，正脸微笑
  - `working-and-waiting.mp4` — 干活 / 等待中，戴蓝色耳机抱着蓝白条纹笔记本
  - `making-something.mp4` — 制作中，捧着发光泡泡
  - `milestone-level-up.mp4` — 完成里程碑时

## 使用
免费分享，欢迎拿去做你自己的 Muse 头像、表情、二创。发帖/转发时注明出处即可。
